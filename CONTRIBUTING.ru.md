# Участие в проекте

[English](CONTRIBUTING.md) | [Русский](CONTRIBUTING.ru.md)

turnrelay в стадии беты, участие приветствуется.

## Базовые правила

- **Область.** Это транспорт для обхода цензуры, для исследовательского и
  личного использования. Вклад должен служить этому; никаких инструментов для
  фермы аккаунтов, решения капчи как сервиса или массового таргетинга.
- **Лицензирование.** Проект под GPL-3.0. Вносите только код, который можете
  лицензировать под GPL-3.0. Не вставляйте код из
  PolyForm-Noncommercial или иных несовместимых источников; при портировании
  из GPL-проекта отмечайте это в заголовке файла и в `NOTICE`.

## Разработка

```bash
make test    # go test -race ./...
make vet     # go vet ./...
make build   # bin/turnrelay-udp
```

- Тесты идут в процессе против локальных заглушек (сервер pion/turn, obfs-
  серверы) и никогда не трогают VK. Так и держите; тест против живого VK -
  это ручной runbook, а не `go test`.
- Новое поведение идёт с тестом. Придерживайтесь окружающего стиля.

## Сообщения об ошибках

- Баги и изменения протокола (VK меняет свой API - поломки там обычны):
  открывайте issue с релевантными строками лога. Не вставляйте реальные
  ссылки на звонки, учётные данные или IP серверов.
