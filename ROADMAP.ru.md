# Дорожная карта

[English](ROADMAP.md) | [Русский](ROADMAP.ru.md)

`turnrelay` в стадии беты. Здесь - где он сейчас и куда движется. Порядок и
объём могут меняться.

## Готово

**Ядро транспорта (библиотека + CLI).**

- Go-библиотека `turnrelay`: N TURN-аллокаций как единый UDP-dialer
  (`DialContext`/`ListenPacket`), пригодный как `N.Dialer` для sing-box.
- Режимы обфускации: `srtp` (DTLS-SRTP, по умолчанию), `wrap`
  (RTP-конверт в стиле WDTT), `dtls` (legacy).
- Провайдеры учётных данных: `vk` (анонимный вход по ссылке на звонок VK, с
  автоматическим решением капчи) и `static` (фиксированные данные для любого
  релея, например self-hosted coturn).
- Пул учётных данных с учётом квоты: около 18 аллокаций на credential,
  автоматический перезапрос, кулдауны, uplink с work-stealing без потери
  датаграмм.
- CLI `turnrelay-udp`: локальный UDP-мост, на который указывает
  WireGuard-клиент, так что транспорт уже работает с sing-box (или любым
  WireGuard-клиентом).
- Серверная сторона: работает с немодифицированной upstream-серверной частью;
  включены docker-тест на совместимость и скрипт настройки VPS.

## Дальше

**Нативный outbound для sing-box (главная цель).**

Добавить тип outbound `turnrelay` в sing-box, чтобы конфиг был одним блоком и
отдельный процесс `turnrelay-udp` был не нужен:

```json
{ "type": "turnrelay", "tag": "relay", "provider": "vk",
  "call_link": "https://vk.ru/call/join/<hash>",
  "server": "<vps-ip>", "server_port": 56004,
  "connections": 18, "mode": "srtp" }
```

Тогда endpoint `wireguard` использует его через `detour`. Именно это делает
turnrelay пригодным внутри клиентов на базе sing-box (в том числе на iOS, где
лимит «один VPN» исключает второе приложение). Черновик предложения для
upstream - в [docs/sing-box-rfc.md](docs/sing-box-rfc.md); outbound также
работает как внешний модуль для клиентов, которые регистрируют его сами.

## Позже

- **Больше совместимости по обфускации.** Проверенная совместимость `wrap` с
  серверными семействами WDTT и FreeTurn; режим CSQTT (RTP/VKQUIC).
- **Больше провайдеров учётных данных.** Транспорт не привязан к VK. Другие
  сервисы звонков с релеями в вайтлисте можно добавить как провайдеры.
- **Транспорт для Xray.** Тот же dialer для Xray-core, если мейнтейнеры
  будут не против.
- **Режим proxy-exit на сервере.** Сервер, пробрасывающий произвольные
  адреса назначения, чтобы WireGuard не требовался в каждом развёртывании.

## Не цели

- Никакого plaintext / без-обфускации режима - он приводит к банам аккаунтов.
- Никакого сервиса по решению капчи или фермы аккаунтов.
